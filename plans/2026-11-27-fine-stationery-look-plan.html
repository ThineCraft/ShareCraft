Fine Stationery: implementation plan

27 November 2026. Branch fine-stationery in H:\Source\repos\ThineCraft\ShareCraft-stationery, from main 2654a64. Spec: 2026-11-27-fine-stationery-look.html (approved by the owner). Executors read both.

For agentic workers: use superpowers:subagent-driven-development or superpowers:executing-plans, task by task. Each step is a checkbox.

Goal: a built-in theme "Fine Stationery" and a look setting Page: Plain or Paper, chosen on Change the look.

Architecture: the theme is one more entry in BUILT_IN_THEMES with explicit dark colours. Page is a new Look field that follows the menu style through storage, input, effective look, templates and history. Paper colours and grain are fixed CSS under [data-page="paper"], an attribute the page and the preview set through setAttribute.

Tech stack: Rust (crates revisions, server), plain ES modules in web/, node --test.

Global constraints

  • Build target: $env:CARGO_TARGET_DIR='J:\cargo-target\sharecraft-stationery' (its own, so xtask acts on this worktree).
  • Locally run targeted tests only; the full suite runs on GitHub Actions when the owner pushes.
  • Commit on fine-stationery only. No merge, push or tool install without the owner's go-ahead. Every commit ends with Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>.
  • Theme: id builtin:stationery, name Fine Stationery, primary #203c50, secondary #172f40, primary_dark #b4d5ed, secondary_dark #182b3a.
  • Paper colours, light / dark: bg #f9f7f2 / #10151b; paper and sheet #fdfcf9 / #1c232b; text #252b30 / #f0ede6; muted #667079 / #b9c4cd; champagne #b29a70 / #c7ad82.
  • No colour of a page ever comes from user input; no images, no SVG filter, no Content Security Policy change; the editor frame never takes Paper.
  • Wording in the interface and BUILDING follows the house style: plain words, "Page", "Plain", "Paper".

Review focus

  1. A look stored before this change (no page) reads as Plain and is written back byte for byte the same (Task 2 test).
  2. A site in a hub keeps its own Page; the hub's Paper is never applied to it (Task 2 test).
  3. Switching the draft from Paper back to Plain clears the attribute on both preview panels; a site page whose look cannot be read has no attribute (Task 3 test of applyPage).
  4. Printing a Paper page shows no grain (Task 4: @media print rule, checked by the style test).
  5. At 375 px the fixed grain layer causes no horizontal scroll and covers the whole page while scrolling (Task 5 browser check).
