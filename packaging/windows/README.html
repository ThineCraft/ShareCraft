1. What it is

ShareCraft is an open-source place to keep and share documents, in the spirit of SharePoint: sites, libraries, folders, sharing with people and groups, and editors for text, spreadsheets, word documents, PDFs and 3D designs, all in the browser.

This folder holds everything already built:

2. What you need

  • Windows 11 (64-bit), signed in as the person who will run ShareCraft.
  • About 2 GB of free disk space: about 800 MB for the program, and the rest for the database and your documents to start with.
  • A web browser (Edge, which comes with Windows, is fine).

You do not need administrator rights, a compiler, Git or PostgreSQL. Nothing is installed for other Windows users, and no Windows service is added.

3. Installing

  1. Copy this whole folder (or the zip, then unzip it) anywhere on the computer, for example to Downloads. Do not run it from inside the zip.
  2. Double-click Install ShareCraft.cmd. If Windows asks whether to run a file from the internet, choose to run it.
  3. Answer the questions in the window:
    • the first administrator's email address and name;
    • whether to start ShareCraft when you sign in to Windows (the default is No);
    • then the administrator's password, at least 10 characters. It is asked for by ShareCraft itself and is not shown while you type.
  4. Wait a few minutes. The installer copies the program, makes the database, switches on the stand-in scanner, adds Start-menu shortcuts, starts everything and opens ShareCraft in your browser. Press a key to close the window when it says it has finished.

%LOCALAPPDATA% is your own local application folder, usually C:\Users\<you>\AppData\Local. To open it, type %LOCALAPPDATA%\ShareCraft into the address bar of File Explorer.

ShareCraft itself uses the first free port from 8787 to 8799, and the stand-in scanner the first free port from 1344 to 1354. The installer says which ones it picked.

If ShareCraft is already installed for you, the installer stops and changes nothing; see Installing a newer copy.

4. Signing in

Open the address the installer showed, for example http://127.0.0.1:8787/, and sign in with the administrator's email address and password. As administrator you can add people on the People page, make sites, and change the organisation settings.

Use 127.0.0.1 or localhost in the address; other names for the computer are refused.

ShareCraft runs only while you have started it; it does not start by itself after Windows restarts unless you chose start when I sign in during installation. Signing out of Windows ends it.

Stop after saving. Stopping ends ShareCraft at once. Changes typed in the last few seconds (at most 30 seconds) before stopping may be lost; everything saved before that is kept. Wait until the page says Saved before you stop.

6. Where your data lives, and backups

Everything that is yours is in one folder: %LOCALAPPDATA%\ShareCraft. The documents are in data, and accounts, sharing and history are in the database in db. Both are needed; neither is enough alone.

To make a backup

  1. Run Stop ShareCraft and wait for its message. (Copying while it runs can give a database copy that does not work.)
  2. Copy the whole folder %LOCALAPPDATA%\ShareCraft somewhere safe, such as an external drive.
  3. Start ShareCraft again.

The copy includes .env, which holds the database password: keep the backup as private as the computer itself.

To restore a backup

Stop ShareCraft, put the copied folder back as %LOCALAPPDATA%\ShareCraft (replacing what is there), and start ShareCraft again. To restore on another computer, or for another Windows user, install there first, stop it, replace the folder, then run the installer again with -Reinstall (next sections) so it checks the ports.

7. The malware scanner, and ClamAV

ShareCraft can send every uploaded file to a malware scanner before anyone may open it. So that this can be tried at once, the installer switches on a stand-in scanner. It is not antivirus: it only recognises the standard EICAR test text (a harmless string made for testing scanners) and calls every other file clean.

To use a real scanner, run ClamAV with c-icap (its ClamAV service) on a computer you control, then, signed in as administrator, open Organisation settings (the address ends in /sharing.html), find Malware scanner, and set the scanner address to your scanner's, for example icap://scanner.example.org:1344/srv_clamav. The part after the last / is whatever your scanner calls its service. Saving tests the address at once and says whether the scanner answered.

The stand-in keeps running in the background after that; it does no harm. To switch scanning off altogether, empty the scanner address.

ShareCraft has been tested only against the stand-in, not against a real ClamAV. Try a real scanner with a test file before relying on it.

8. Your computer's own antivirus

Windows Security (or other antivirus) may delete files ShareCraft has stored. It watches the data folder like any other folder. If you upload the EICAR test file to try the scanner, your antivirus may remove the stored copy, and ShareCraft then reports the file's content as missing. This is your antivirus working, not a fault in ShareCraft. To try the scanner, use a file with some other text before the test string, and delete it afterwards.

9. Limits

  • This computer only. ShareCraft answers only at http://127.0.0.1:<port> on this computer. Phones, other computers and other people on your network cannot reach it. That needs a production mode that is not built yet.
  • No HTTPS. The connection is plain HTTP, which is acceptable only because it never leaves the computer.
  • For one Windows user. It is installed for the Windows user who ran the installer. Other people can still have ShareCraft accounts and use them from this computer's browser.
  • Not a Windows service. It runs while started and stops when you sign out.
  • No automatic updates and no signed installer. Windows may warn about running the scripts; that is expected.
  • Folder names. A Windows user folder with spaces or letters such as ë (for example C:\Users\Zoë Smith) works: the database programs cannot read such letters, so the scripts give them the folder's short name instead (like ZOSMIT~1), which Windows keeps on the system drive. On a drive where Windows keeps no short names, the installer stops before copying anything and says so.

10. Installing a newer copy

To install a newer (or the same) copy over the one you have, keeping all documents, accounts and the database:

  1. Unzip the new copy anywhere.
  2. Open a Command Prompt in that folder (in File Explorer, type cmd into the address bar and press Enter).
  3. Run:
"Install ShareCraft.cmd" -Reinstall

It stops ShareCraft, replaces the program in %LOCALAPPDATA%\Programs\ShareCraft, keeps %LOCALAPPDATA%\ShareCraft as it is (only the port numbers change, if another program has taken one meanwhile), and starts ShareCraft again. It does not ask for an administrator, because the accounts are kept. The new server brings the database up to date by itself when it starts.

11. Uninstalling

Choose Uninstall ShareCraft in the Start menu. It asks first whether to remove ShareCraft, stops everything, then asks:

Also delete all ShareCraft data and the database? [y/N]

  • Answer N (or just press Enter) to keep %LOCALAPPDATA%\ShareCraft. Only the program and the shortcuts are removed, and installing again with -Reinstall brings everything back.
  • Answer y to delete the documents, the accounts and the database as well. This cannot be undone, so make a backup first if you might want them.

Nothing is deleted without that answer. The uninstaller does not touch this folder (the one you installed from); delete it yourself when you no longer need it.

12. When something goes wrong

Common problems
What you seeWhat to do
"ShareCraft is already installed for this Windows user"Nothing was changed. To install over it and keep your data, use -Reinstall (section 10). To start afresh, uninstall and delete the data first (section 11).
"There is no free port for ..."Other programs use every port in that range. Close one of them, or restart Windows, and run the installer again.
"ShareCraft did not answer within 60 seconds"It may still be starting on a slow disk: try the address again a minute later. Otherwise read logs\server.err.log in %LOCALAPPDATA%\ShareCraft.
"Starting the database ... failed"Read logs\postgresql.log. A database that was not stopped cleanly usually starts again after Stop ShareCraft and then ShareCraft.
The administrator was not createdThe installer offers three tries. The password needs at least 10 characters.
A first install stopped half wayIt takes back what it made, so you can simply run it again.

The logs never contain the database password or address. If you ask someone for help, send the log files, never .env.

13. What has and has not been checked

Checked, on the build computer (Windows 11, Windows PowerShell 5.1):

  • The scripts' automated self-tests: port picking, quoting of folder names with spaces and non-ASCII letters, the narrowed access list on .env, that no password reaches the window or the files around it, that a reinstall keeps data and the database, and that uninstalling keeps data unless told otherwise.
  • One full install from the package zip into a temporary profile folder whose name had a space and an ë: the database was made, the administrator could sign in, the scanner address was set, Stop and Start worked, a second install was refused, a reinstall kept the data, and uninstalling with deletion confirmed removed everything. The installer was given its answers by a script there, not typed.

Not checked:

  • A second, clean Windows 11 computer, or a Windows user account whose real profile folder has non-ASCII letters (only a temporary folder was used).
  • Double-clicking the installer and typing the answers by hand, and the Start-menu shortcuts' message windows (the scripts behind them were run directly).
  • Start when I sign in, after a real sign-in.
  • SmartScreen or antivirus warnings on another computer, and computers where scripts are restricted by an organisation's policy.
  • A real ClamAV scanner.
  • Restoring a backup on another computer.
