Unfinished features and how they stay off

  • G5 live editing: the page enters live mode only when the document answer carries session: "live". That needs SHARECRAFT_LIVE_EDITORS=gridcraft (unset by default) and an installed GridCraft build whose editor.json declares the live protocol and the gridcraft/1 format; one helper, ws::room_kind_for, decides this for both the document answer and the WebSocket. Without both, GridCraft documents open as ordinary file sessions. Do not switch it on in production before G5 Task 8 (compaction) and the final review.
  • File Share: the approved roots setting defaults to empty, so every connect is refused; no page uses the File Share routes yet.
  • S3: only the signing library exists; nothing reaches it.

Open items to remember

  • Uploading a new version while a live session is open returns a bare 503; G5 should answer "being edited".
  • "Download my copy" after a stopped live session needs GridCraft to hand over its bytes on request; it currently hands over nothing in live sessions.
  • A column or row can be frozen for a session by heavy insert/delete churn until G5 Task 8 adds compaction of deleted identity runs.
  • The client library's Event::Saved does not carry mismatch; the page reads it from the raw frame.
  • Development databases that applied an earlier copy of migration 0020 (G4's or File Share's) must be reset.
  • Nothing in the live-editing work has been tried in a real browser yet.
