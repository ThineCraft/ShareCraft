ThineCraft project scope

ShareCraft

Status: Placeholder project. This document describes intended direction; it does not claim that working functionality exists.

Project website

Purpose

ShareCraft is the planned open-source SharePoint alternative and shared-content foundation of the ThineCraft family. It is intended to help organizations publish, govern, search, collaborate on, and retain ownership of organizational knowledge.

Confirmed direction

  • Team sites, communication sites, intranets, departmental portals, pages, news, and navigation.
  • Document libraries with folders, managed metadata, versions, search, permissions, sharing, retention, auditability, and governance.
  • Lists for structured information, lightweight tracking, and operational records.
  • Controlled public submission surfaces that can receive records without exposing private workspaces.
  • Workflow and integration points for FlowCraft and other compatible systems.
  • Presence and co-authoring support for WordCraft, GridCraft, PdfCraft, SolidCraft, DeckCraft, and future compatible applications.
  • Portable data, open interfaces, hosted deployment, self-hosting, and hybrid continuity.

Boundaries and non-goals

  • ShareCraft is a general SharePoint replacement, not an event-specific product.
  • ThineWedding, ThineMemorial, and ThineCapture are services built on ShareCraft; they are not separate ShareCraft core projects and do not define its architecture.
  • Document editors and CAD tools remain separate applications. ShareCraft provides shared content, identity, governance, presence, and co-authoring infrastructure.
  • No implementation, compatibility level, release date, or production readiness is currently promised.

Expected integrations

  • DriveCraft for synchronization, migration, metadata visibility, and offline continuity.
  • FlowCraft for inspectable workflows, approvals, and integrations.
  • TeamCraft, GanttCraft, ShowCraft, and FormCraft for context-linked collaboration.
  • WordCraft, GridCraft, PdfCraft, SolidCraft, and DeckCraft for co-authoring.
  • Microsoft SharePoint and Microsoft Graph where migration or interoperability requires them.

Open decisions

  • Identity, tenancy, permissions, federation, and policy model.
  • Canonical content, metadata, versioning, search, and event schemas.
  • Storage architecture and the division between hosted, self-hosted, and hybrid services.
  • Co-authoring protocol, conflict resolution, presence, and offline reconciliation.
  • Migration guarantees and compatibility boundaries with Microsoft 365.
